# Shortly-URL-shortener

A clean, minimalist, and basic URL shortener project to easily shorten long links and track recent history.

## Run Locally

**Prerequisites:** Node.js

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the app:**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
